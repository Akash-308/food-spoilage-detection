# Food Spoilage Detection System

## 📌 Overview
This project detects gas leakage and food spoilage using an MQ-6 gas sensor. It alerts users through LEDs and a buzzer when gas levels exceed a safe threshold.

---

## 🚀 Features
- Real-time gas monitoring  
- LED indication (Safe / Danger)  
- Buzzer alert system  
- Non-blocking firmware using millis()  
- Low-cost embedded solution  

---

## 🛠️ Components Used
- Arduino UNO  
- MQ-6 Gas Sensor  
- Red LED  
- Green LED  
- Buzzer  

---

## ⚙️ Working
- MQ-6 sensor reads gas levels (analog input)  
- If value > threshold:
  - Red LED ON  
  - Buzzer ON  
- Else:
  - Green LED ON
